PROJECT PINK — iPhone web app prototype

Files: upload every file in this folder to the root of a GitHub repository.

Free hosting with GitHub Pages (iPhone Safari):
1. Sign in at https://github.com and create a NEW PUBLIC repository (for example project-pink).
2. In the repository, choose Add file > Upload files. Upload index.html, manifest.webmanifest, sw.js, icon-180.png, icon-192.png and icon-512.png. Commit the files.
3. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch, select main and /(root), then Save.
4. Wait for GitHub Pages to publish. Open the published https://YOUR-USERNAME.github.io/project-pink/ address in Safari.
5. Tap Share > Add to Home Screen. Enable Open as Web App if shown, then tap Add.

Privacy and limitations:
- Journal data is stored locally in this browser on this device. It is not synced to another device.
- The PIN is a convenience lock only, not encryption. Do not store highly sensitive information.
- Export a backup periodically. Clearing Safari website data can erase entries and photos.
- Photo storage uses browser storage and can fill up; use modest image sizes.
- Reminder time is saved as a preference; background notifications are not implemented in this prototype.
- GitHub repository is public, so the app's source code is visible. Your journal contents are not uploaded to GitHub by this app.
